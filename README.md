[View the project](https://aymaneldawy.github.io/RM-word/index.html)

- Frontend assets organised in a source and distribution workflow
- Published as a fast, no-framework GitHub Pages site

This repository is a frontend showcase project. It reflects hands-on work with the foundations of web development, build tooling, and deployment.
